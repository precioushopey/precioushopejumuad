# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Personal portfolio site for Precious Hope Jumuad (React 19 + TypeScript + Vite 6 + Tailwind CSS v4), deployed on Vercel.

## Commands

- `npm run dev` — Vite dev server
- `npm run build` — `tsc -b && vite build` (type-check is part of the build)
- `npm run lint` — ESLint (flat config in `eslint.config.js`)
- `npm run preview` — serve the production build

There is no test framework configured.

## Architecture

- **Routing is fully manual, in `src/App.tsx`.** Every project and blog post has its own hand-registered `<Route>` and import (`/projects/<slug>`, `/blogs/<slug>`). Blog components are imported as `Blog1`, `Blog2`, ... `Blog16` (numbering has gaps, and doesn't follow date order). `vercel.json` rewrites all paths to `/` so client-side routing works on deploy.
- **All routes are nested under the `Shell` layout route** (`src/components/shell/`). `Shell` provides the fixed blurred, darkened background, the `TopBar` (greeting + `SearchPill`), the main `glass-panel` (the only `<main>`; on desktop only it scrolls; below `lg` it has no background, border or blur, so the content sits directly on the page background), the floating icon `Rail` (on desktop a tall frosted side rail with square right corners, absolutely positioned inside the content row, 28rem tall, tucked under the panel's left edge; below `lg` a sticky bottom bar; last in the DOM for tab order), and a right column (`ProfileCard` + `ContactCard`) shown only on `/`, `/about`, `/projects`, `/blog` (beside the panel from `xl` up (1280px); below that it is a page of its own at `/profile`, reached from the dock avatar (lg to xl) or the phone bar's avatar item (below lg); `/profile` redirects home from xl up). On desktop the content row is only as tall as its content (capped at the window height) and the header + row group is vertically centered, so the panel and the right column always end on the same line and tall windows get equal space above and below; Home's grid stretches to fill the panel. Below `lg` the page scrolls normally. Links with a `#section` (e.g. `/about#contact`) make `Shell` jump to that element, scrolling the panel on desktop and the window on mobile; no link uses this right now, but it is kept. Pages render only their own content and must not add their own navbar or background. The `Rail` marks the active item with `data-active`; CSS anchor positioning in `src/index.css` glides one indicator to it (a yellow pill on phones, the vertical bar on desktop; Firefox falls back to the static per-item style). The active item shows its title: beside the icon on phones, in small type under the icon on desktop. Don't put `overflow-x-hidden` on the `Shell` root: it turns the root into a scroll container and breaks the sticky mobile rail (use `overflow-x-clip`).
- **Each project/blog is a standalone page component** in `src/projects/` or `src/blogs/`, with its content (copy, image paths, tags, design-step data) written inline in the JSX. There is no CMS or markdown pipeline.
- **Listing data lives in `src/data/`.** The `projects` array (`category` filter: frontend/design/socials/multimedia) and the `blogPosts` array feed the listing pages, the home-page counts, and the top-bar search (`src/lib/search.ts`). `src/data/contact.ts` holds the contact links used by the profile card's icon row. `ContactForm` (used by `ContactCard` in the right column) does NOT deliver messages: it only shows a fake "Message sent!" toast. `src/data/links.ts` holds `CV_URL`; the profile card's "View my CV" button only renders when it is non-empty. Adding a project or post means touching three places: the new page file, a `<Route>` in `App.tsx`, and an entry in the matching `src/data/` array.
- **Home is a widget dashboard** (`src/pages/home.tsx`): Featured pill tabs, then a grid of two rows of two, where cards in a row stretch to the same height: row 1 = Recent Projects | (a clock that always shows Philippine time (`PhilippineClock`, using `Asia/Manila` via `src/lib/manilaTime.ts`, never the visitor's timezone) + two plain stats on soft yellow tiles (`Stat`: the Projects and Blog posts counts; the Blog posts one has a hover/focus `tip` explaining the goal of 55, i.e. 1 blog at age 21, 2 at 22 … 10 at 30, set by the `GOAL_*` constants in `home.tsx`), over Skills & Expertise (`SkillsCard`: icon rings in a row; each ring fills with that skill's share of total experience since March 1, 2024, via `skillShare` in `src/lib/experience.ts`, from the start dates set in the component — dates use `manilaMidnight` so every visitor sees the same numbers; hovering, focusing or tapping a ring shows a tooltip with how it was worked out, from `skillBreakdown`)); row 2 = Work Experience (`WorkExperience`) | Featured Projects as bare photo cards with no container. The greeting's flag is the inline SVG `PhFlag`, not an emoji (Windows browsers render flag emoji as the letters "PH"). Skills render at the bottom of the About page (contact lives only in the right column). The Projects page has a heading and category pills like Home's Featured header, then a grid of large thumbnails with name and tags. The Blog page uses the same `ThumbnailTile` (date as the details line). Each blog post file is wrapped in `BlogPostLayout` and each project file in `ProjectLayout`, both built on `DocumentWindow` (title bar with the file name, address bar with a back arrow, title and details from `blogPosts`/`projects`; on desktop the main panel itself is the window, below lg it is its own card), so those files only hold their own content. On a post or a project page the right-hand column (`BlogSuggestions`/`ProjectSuggestions` in `SideSuggestions.tsx`; on cards with a "see all" arrow the whole `WindowBar` is the link, via its `to` prop) shows the other posts/projects as thumbnail tiles in a column instead of the profile and its own category pills (`/blog?category=<c>`; each post has a `category` in `src/data/blogPosts.ts`; `PillTabs` takes `categories`/`basePath`). Project category filters live in the URL (`/projects?category=<c>`); `categories` is exported from `src/data/projects.ts`.
- **Styling:** Tailwind v4 via `@tailwindcss/vite` with no `tailwind.config`. Gaps use only 0, 1, 1.5, 2 and multiples of 4 (`gap-4`, `gap-8`, ...; never gap-3, gap-5 or gap-6). The `lg` breakpoint is redefined to 768px in `@theme` (`--breakpoint-lg: 48rem`), so `lg:`/`max-lg:` mean "tablet and up" / "phone" (below 768px); the hard-coded media queries in `src/index.css` use 768px to match. `xl` is still 1280px (where the right-hand column appears). The site is dark-themed. Design tokens live in the `@theme` block in `src/index.css`: `font-display`, `bg-panel`, `bg-card`, `text-cream`, `border-line`, `bg-accent`/`text-accent` honey yellow `#FFC93C`, `text-ink` (only on yellow/white surfaces), plus the `animate-fade-in*` animations. Custom utilities: `glass-panel`, `glass-card`, `pill`, `pill-outline` (use one, not both), `tile-outline`, `arrow-button`, `white-button`, `transparent-button`. Poppins is the UI font; the display font (Unbounded, `font-display`) is used only for the name in the top-bar greeting, and `.font-display` disables synthesized bold. A global `:focus-visible` rule draws a yellow outline, and a base rule gives every link, button, summary, select and label the pointer cursor (`cursor-help` on the tooltip gauges still wins). `text-glow` is a legacy no-op still referenced by old pages. The site is themed as a desktop OS: `WindowBar` (title bar: icon, title, optional action) tops app-window cards on Home (Recent Projects, At a glance, Work Experience; the Skills card deliberately has no title) and the About page (Experiences, Education, Certifications and Skills are large Windows-style folder icons in a grid (`FolderGroup`, one open at a time, starting closed); notes, work experience and education as accordion cards (`AccordionCard`, chevron in the title bar, one card per company or school) with a Task Manager-style Name/Status/Started/Duration table, Certifications and Skills as file-list windows) and the "New message" mail-compose card in the right column; `TrayClock` (Philippine time) sits under the desktop rail avatar; the phone bar shows wifi and battery glyphs from 440px and the clock from 560px, and the widest gap (gap-8) from 560px (earlier thresholds overflow the 5-item bar). Fonts load from Google Fonts in `index.html`.
- **Icons:** Lucide, via `react-icons/lu` (`Lu*` names). Don't import from other `react-icons` sets. Lucide has no filled variants, so the active rail item is shown with a yellow colour and a heavier stroke (`strokeWidth`) instead.
- **Assets:** images are served from `public/assets/images/`, grouped into subfolders (`site`, `profile`, `experience`, `education`, `certifications`, `skills`, `blog`, `projects/<slug>`), and referenced by absolute path (`/assets/images/<group>/...`). The OG/meta tags are in `index.html`. `@vercel/analytics` is mounted in `App`.
