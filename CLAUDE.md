# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Personal portfolio site for Precious Hope Jumuad (React 19 + TypeScript + Vite 6 + Tailwind CSS v4), deployed on Vercel.

## Commands

- `npm run dev` — Vite dev server
- `npm run build` — `tsc -b && vite build` (type-check is part of the build)
- `npm run lint` — ESLint (flat config in `eslint.config.js`)
- `npm run preview` — serve the production build

There is no test framework configured.

## Architecture

- **Routing is fully manual, in `src/App.tsx`.** Every project and blog post has its own hand-registered `<Route>` and import (`/projects/<slug>`, `/blogs/<slug>`). Blog components are imported as `Blog1`, `Blog2`, ... `Blog16` (numbering has gaps, and doesn't follow date order). `vercel.json` rewrites all paths to `/` so client-side routing works on deploy.
- **All routes are nested under the `Shell` layout route** (`src/components/shell/`). `Shell` provides the fixed blurred, darkened background, the `TopBar` (greeting + `SearchPill`), the main `glass-panel` (the only `<main>`; on desktop only it scrolls), the floating icon `Rail` (on desktop a tall frosted side rail with square right corners, absolutely positioned inside the content row, 28rem tall, tucked under the panel's left edge; below `lg` a sticky bottom bar; last in the DOM for tab order), and a right column (`ProfileCard` + `ContactCard`) shown only on `/`, `/about`, `/projects`, `/blog` (beside the panel at `xl`, at the bottom of the panel below). On desktop the content row is only as tall as its content (capped at the window height) and the header + row group is vertically centered, so the panel and the right column always end on the same line and tall windows get equal space above and below; Home's grid stretches to fill the panel. Below `lg` the page scrolls normally. Links with a `#section` (e.g. `/about#contact`) make `Shell` jump to that element, scrolling the panel on desktop and the window on mobile; no link uses this right now, but it is kept. Pages render only their own content and must not add their own navbar or background. The `Rail` marks the active item with `data-active`; CSS anchor positioning in `src/index.css` glides one indicator to it (a yellow pill on phones, the vertical bar on desktop; Firefox falls back to the static per-item style). The active item shows its title: beside the icon on phones, in small type under the icon on desktop. Don't put `overflow-x-hidden` on the `Shell` root: it turns the root into a scroll container and breaks the sticky mobile rail (use `overflow-x-clip`).
- **Each project/blog is a standalone page component** in `src/projects/` or `src/blogs/`, with its content (copy, image paths, tags, design-step data) written inline in the JSX. There is no CMS or markdown pipeline.
- **Listing data lives in `src/data/`.** The `projects` array (`category` filter: frontend/design/socials/multimedia) and the `blogPosts` array feed the listing pages, the home-page counts, and the top-bar search (`src/lib/search.ts`). `src/data/contact.ts` holds the contact links used by the profile card's icon row. `ContactForm` (used by `ContactCard` in the right column) does NOT deliver messages: it only shows a fake "Message sent!" toast. `src/data/links.ts` holds `CV_URL`; the profile card's "View my CV" button only renders when it is non-empty. Adding a project or post means touching three places: the new page file, a `<Route>` in `App.tsx`, and an entry in the matching `src/data/` array.
- **Home is a widget dashboard** (`src/pages/home.tsx`): Featured pill tabs, then a grid of two rows of two, where cards in a row stretch to the same height: row 1 = Recent Projects | (a clock that always shows Philippine time (`PhilippineClock`, using `Asia/Manila` via `src/lib/manilaTime.ts`, never the visitor's timezone) + ring gauges (the Blog posts ring is the post count out of a goal of 55, i.e. 1 blog at age 21, 2 at 22 … 10 at 30, set by the `GOAL_*` constants in `home.tsx`, and `RingGauge` takes an optional hover/focus `tip`), over Skills & Expertise (`SkillsCard`: icon rings in a row; each ring fills with that skill's share of total experience since March 1, 2024, via `skillShare` in `src/lib/experience.ts`, from the start dates set in the component — dates use `manilaMidnight` so every visitor sees the same numbers; hovering, focusing or tapping a ring shows a tooltip with how it was worked out, from `skillBreakdown`)); row 2 = Work Experience (`WorkExperience`) | Featured Projects as bare photo cards with no container. The greeting's flag is the inline SVG `PhFlag`, not an emoji (Windows browsers render flag emoji as the letters "PH"). Skills render at the bottom of the About page (contact lives only in the right column). Project category filters live in the URL (`/projects?category=<c>`); `categories` is exported from `src/data/projects.ts`.
- **Styling:** Tailwind v4 via `@tailwindcss/vite` with no `tailwind.config`. The site is dark-themed. Design tokens live in the `@theme` block in `src/index.css`: `font-display`, `bg-panel`, `bg-card`, `text-cream`, `border-line`, `bg-accent`/`text-accent` honey yellow `#FFC93C`, `text-ink` (only on yellow/white surfaces), plus the `animate-fade-in*` animations. Custom utilities: `glass-panel`, `glass-card`, `pill`, `pill-outline` (use one, not both), `tile-outline`, `arrow-button`, `white-button`, `transparent-button`. Poppins is the UI font; the display font is used only for large accent words, and `.font-display` disables synthesized bold. A global `:focus-visible` rule draws a yellow outline. `text-glow` is a legacy no-op still referenced by old pages. The site is themed as a desktop OS: `WindowBar` (title bar: icon, title, optional action) tops app-window cards on Home (Recent Projects, At a glance, Work Experience; the Skills card deliberately has no title) and the About page (Experiences, Education, Certifications and Skills are `FolderSection` folders that start closed, like File Explorer; notes, work experience with a Task Manager-style Name/Status/Started/Duration table, Education as a File Explorer list with expandable rows, Certifications as a file list) and the "New message" mail-compose card in the right column; `TrayClock` (Philippine time) sits under the desktop rail avatar; the phone bar shows wifi and battery glyphs from 380px and the clock from 440px (wider thresholds overflow the bar). Fonts load from Google Fonts in `index.html`.
- **Icons:** Lucide, via `react-icons/lu` (`Lu*` names). Don't import from other `react-icons` sets. Lucide has no filled variants, so the active rail item is shown with a yellow colour and a heavier stroke (`strokeWidth`) instead.
- **Assets:** images are served from `public/assets/images/` and referenced by absolute path (`/assets/images/...`). The OG/meta tags are in `index.html`. `@vercel/analytics` is mounted in `App`.
